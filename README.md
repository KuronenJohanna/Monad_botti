# Monad_botti
Monad Rekrypähkinä 2024

Tehtävänä oli luoda oma botti pelaamaan korttipeliä Monadin kehittämiä vastustajia vastaan.

Peliin liitytään ja sitä pelataan käyttämällä POST-pyyntöjä, jotka lähettävät tarvittavat parametrit. Projekti sisältää päätöksentekologian, joka määrittää pelin kulun ja lähettää seuraavat siirrot pelipalvelimelle.

Vaatimukset:

100 peliä | Vähintään 100 peliä pelattuna
Erotus < 24 | Keskimääräinen erotus vastustajien pisteisiin on pienempi kuin 24 pistettä
Lopulta parhaiden käytäntöjen noudattaminen ja siisti toteutus ovat tärkeämpiä kuin botin suorituskyky.

Projekti hyödyntää seuraavia teknologioita:

Node.js: Backend-kielenä, tarjoaa alustan JavaScriptin suorittamiseen palvelinpuolella.
Axios: HTTP-kirjasto API-pyyntöjen tekemiseen.
dotenv: Ympäristömuuttujien hallintaan, kuten API-tunnusten turvalliseen tallentamiseen.
JavaScript (ES6+): Koodilogiikan toteutukseen.
Git: Versionhallintaan.
JSON: Tietojen hallintaan ja muokkaamiseen API:n kanssa.
